# Smart Money · закритий сайт

Вхід лише за паролем. Усередині: панель (макет за твоїм скріншотом), скан усіх USDT-перпетуалів кожні 15 хв, сигнали,
Машина часу, анти-FOMO фільтр, додавання ключів будь-якої біржі, пуш на телефон, автоторгівля (за замовчуванням вимкнена).

## Розгортання (Railway / Render / VPS)
1. Залий папку в ПРИВАТНИЙ репозиторій. Створи сервіс із цього репо (Dockerfile або Procfile).
2. **Змінні середовища** (обов'язково):
   - `SECRET_KEY`: довгий випадковий рядок, від 32 символів (з нього шифрується сейф ключів)
   - `SITE_PASSWORD`: твій пароль, від 10 символів
   - `DATA_DIR=/data` і ПІДКЛЮЧИ VOLUME на `/data`, інакше після кожного деплою зникнуть ключі й історія
   - `TRUST_PROXY=1` (за проксі Railway/Render)
   - (за бажанням) `ALLOWED_IPS=твій.ip` повністю закриє сайт для всіх інших IP (вони бачитимуть 404)
3. Відкрий URL, увійди. Біржі: вкладка «Біржі». Режим і ліміти: «Налаштування».

## Сповіщення на телефон
- **Web Push:** `python gen_vapid.py` → два рядки в змінні `VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`. На телефоні відкрий сайт,
  «Додати на головний екран» (iPhone: iOS 16.4+), вкладка «Сповіщення» → «Увімкнути push».
- **ntfy** (`NTFY_TOPIC`) і **Telegram** (`TELEGRAM_TOKEN`, `TELEGRAM_CHAT_ID`) працюють паралельно.

## Торгівля
За замовчуванням paper і sandbox. Для live на сервері треба `ALLOW_LIVE=yes`, у сайті фраза підтвердження;
автоторгівля на live ще й `I_ACCEPT_LIVE_AUTO=yes`. Запобіжники: ризик на угоду, ліміт розміру, угод на день, денний збиток,
кнопка STOP. SL/TP прикріплюються через уніфіковані параметри ccxt: перевір на sandbox кожної біржі.

## Безпека (що вбудовано)
Пароль PBKDF2, 5 невдалих входів = блок 15 хв, сесія HttpOnly+Secure+SameSite=Strict, CSRF-токен на кожну зміну,
сейф ключів шифрується Fernet, ключі ніколи не повертаються в браузер, CSP без inline-скриптів, X-Frame-Options DENY,
noindex. Ключі біржі роби лише з правом Trade, без Withdraw, з білим списком IP сервера.
Тести: `python -m unittest discover -s tests -v`
